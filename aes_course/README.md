# Учебный курс AES-128

Начните с [рабочей тетради](WORKBOOK.md), затем дописывайте [student.py](student.py).
Все команды ниже выполняются **из корня репозитория**, где находится `main.py`.

```powershell
python -m aes_course.checks parse_hex_block
python -m aes_course.checks
```

Для чтения курса и запуска проверок достаточно Python, Qt не требуется.
Код выхода 2 означает, что есть незавершённые задания; 1 — ошибка; 0 — все
выбранные проверки пройдены. Сам алгоритм оставлен ученику.

Содержимое папки:

- `student.py` — функции, которые дописывает ученик.
- `constants.py` — готовые справочные таблицы.
- `checks.py` — проверки шагов и обвязка обработки блока.
- `lessons.py` — исходные тексты уроков.
- `WORKBOOK.md` — тетрадь для чтения без приложения.
- `qml/` — интерфейс практики и карточки заданий.

После изменения текстов уроков обновите тетрадь:

```powershell
python -m aes_course.lessons
```

В основном приложении курс подключается через `backend.py` и `qml/AesPage.qml`.
Общие компоненты окна и интеграционные тесты остаются в основном проекте.
