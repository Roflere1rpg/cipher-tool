# Шифры — приложение на Python и QML

Приложение содержит шифры Цезаря, Виженера, XOR, Атбаш, аффинный шифр и AES-128.
Команды выполняются из корня репозитория, где находится `main.py`.

Рабочие шифры находятся в разделе «Симметричные». Раздел «Асимметричные»
знакомит с шифрованием открытым ключом, а «Сравнение» объясняет различия.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## AES с просмотром шагов

Откройте «Симметричные → AES». Во вкладке «Теория» описаны раунды и операции.
Вкладка «Практика» показывает, как меняются байты введённого блока.

1. Выберите шифрование или расшифровку.
2. Введите блок и ключ: каждый по 16 байтов, то есть по 32 Hex-цифры.
   Пробелы разрешены. Кнопка «Пример» заполняет контрольные данные.
3. Нажмите «Зашифровать» или «Расшифровать». Результат можно скопировать.
4. Просматривайте все 42 шага кнопками «Назад» / «Далее» или выбирайте шаг из списка.
   Матрицы показывают состояние до и после операции, зелёные клетки — изменившиеся значения.
5. Для AddRoundKey показан используемый ключ. Ниже приведены все ключи K0…K10.
6. Кнопка обратной обработки переносит результат во вход и меняет направление.

Реализован полный AES-128 для одного блока: начальный AddRoundKey,
девять полных раундов и десятый без MixColumns. Для расшифровки показаны
обратные операции и обратный порядок ключей. Работа с произвольными текстами,
режимы для длинных сообщений и AES-192/256 в эту страницу не входят.

## Код приложения

- `aes_cipher.py` — проверенный код студента из `aes_course/cтудент 21.11.26`;
  к нему добавлены проверка длины блока/ключа и снимки промежуточных состояний.
- `aes_constants.py` — таблицы AES, необходимые приложению.
- `aes_service.py` — перевод снимков в данные для интерфейса.
- `backend.py` — связь QML и Python.
- `qml/AesPractice.qml`, `qml/AesState.qml` — рабочая страница и матрица байтов.

Учебный курс сохранён отдельно в [aes_course/](aes_course/README.md).
Приложение не импортирует его модули и не показывает задания, проверки уроков или тетрадь.
Исходный файл решения студента сохранён без изменения.
